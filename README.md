## TVMsim

고속철도 신호 시스템(TVM430 · 연동장치 · CTC)을 단순화해 구현한 Python 시뮬레이터

## 동기

2026년 11월, 경부고속선 동대구–경주 구간에서 열차 한 대가 고장 나면서 12시간 가까이 지연여파가 있었음. 이 일을 계기로 고속철도가 열차 간격을 어떻게 유지하는지, 분기에서 충돌을 어떻게 막는지, 이상 상황을 누가 어떻게 처리하는지 궁금해짐.

이 프로젝트의 목표는 구조를 직접 만들어 보며 이해하는 것과, Python 언어와 생태계에 익숙해지는 것임.

## 모델링 대상
 
| 계층 | 실제 시스템 | 이 프로젝트에서의 역할 |
| --- | --- | --- |
| 선로 | 폐색 구간, 분기기, 신호 | 블록·분기기·신호를 노드로 하는 방향 그래프 |
| 점유 검지 | 궤도회로 | 열차 위치로 블록 점유 상태 갱신 |
| 연동장치 | 전자연동장치 | 진로 설정 조건 검사, 쇄정·해정, 겹치는 진로 배제 |
| 열차 방호 | TVM430 차내신호 | 가장 가까운 정지점까지의 블록 수로 속도코드 계산 |
| 열차 | 차상 장치 + 기관사 | 가감속, 코드 추종, 과속 시 자동 제동 |
| 관제 | CTC, 자동진로설정 | 운행계획 기반 진로 요청, 수동 진로 변경 |

## 프로젝트 구조
```
train-sim/
├── main.py           # 실행 진입점
├── trainsim/         # 시뮬레이션 패키지 (track, interlocking, tvm, ctc, render)
├── data/             # 배선 YAML
├── tests/            # pytest
├── docs/             # 설계 노트
└── requirements.txt
```

## 실행 방법

bash
git clone <repository-url>
cd train-sim
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py

## Reminder
이 프로젝트는 학습용 시뮬레이터이다.

블록 길이를 일정하게 두고, 속도코드 단계는 단순화 되었다.
실제 연동장치와 ATP는 SIL4 등급으로, 다중화 하드웨어와 형식 검증, 독립 안전 평가를 거친다. 이 프로젝트는 그런 안전 공학의 요구사항은 다루지 않는다 (못한다). 블록 단위 동작이 직관적인 TVM 방식을 먼저 구현하였다.
